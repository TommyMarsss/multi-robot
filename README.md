# 多机器人编队保持：领航-跟随控制

纯 Go 标准库实现的领航-跟随编队控制器，附带单文件 HTML 轨迹回放。覆盖三个核心问题：**转弯时的队形几何形变**、**避碰与队形目标的冲突仲裁**、**大偏差后的渐进恢复**。

## 运行

```bash
go run ./cmd/sim     # 仿真并生成 formation.html，浏览器直接打开即可回放
go test ./...        # 自动化测试
```

回放页面：逐帧播放领航者（三角）与跟随者轨迹，虚线菱形为各跟随者的期望位置；红色高亮避碰触发帧、橙色高亮队形偏差超限帧，右侧事件列表可点击跳转。

## 一、队形坐标定义与转弯几何形变

跟随者偏移**不**使用世界系固定笛卡尔偏移，而是定义在随领航者航向旋转的**路径坐标系**（Frenet 系）：

```
t = (cosθ, sinθ)        切向（领航者航向）
n = (-sinθ, cosθ)       左法向
Offset = (s, d)         s=切向偏移(前正)，d=法向偏移(左正)

期望位置: p_des = p_L + s·t + d·n
```

若使用世界系固定偏移，领航者转弯时内外侧跟随者到转弯中心的半径相同，会被迫以相同角速度走不同半径的弧——外侧跟不上、内侧超前，队形剪切甚至相互碰撞。

路径坐标系下，法向偏移为 d 的跟随者走的是半径 R−d 的同心弧，其速度必须与领航者成比例。对 p_des 沿路径求导得到**转弯前馈修正**（`controller.go` 的 `Desired`）：

```
v_des = v·(1 − κ·d)·t  +  v·κ·s·n
```

- `(1 − κ·d)`：内外侧速比修正项。左转（κ>0）时左侧（d>0）为内侧，速度自动减小；外侧自动增大。
- `v·κ·s·n`：切向偏移 s 在转弯时产生的侧滑分量。

控制律为「前馈 + PD」：`a = KP·(p_des−p) + KV·(v_des−v)`，前馈项使转弯时跟踪误差保持有界（测试 `TestTurnGeometryDeformation` 验证：连续左右转弯下误差 < 0.6m，外侧平均速度显著大于内侧，全程无碰撞）。

## 二、避碰与队形冲突的仲裁策略

**优先级（高→低）：避碰 Avoid > 恢复 Recover > 队形 Normal。**

- **触发/退出采用滞回**：间距 < `AvoidEnter`(1.6m) 进入避碰，> `AvoidExit`(2.0m) 才退出。滞回带防止在阈值附近来回切换（震荡）。
- **避碰模式下的合成**：`a = a_avoid + w·a_form`，其中 `w = AvoidFormWeight`(0.25) < 1。避碰斥力全量生效，队形项降权保留（避免完全丢弃队形目标导致退出避碰后误差过大），两者**不等权叠加**，从机制上避免两个目标拉扯震荡。
- **队形本身不可行时**（期望间距 < 安全距离 `DSafe`）：系统稳定停留在避碰模式，实际间距收敛到斥力与降权队形力的平衡点（> DSafe），而不是在两个目标间抖动。这是可接受的稳态——不可行的队形目标被安全约束覆盖。
- **硬限幅**：任何模式下 `|a| ≤ AMax`、`|v| ≤ VMax`，绝不输出超出动力学能力的指令。

测试 `TestConflictArbitrationPriority`：期望间距 0.6m < DSafe 1.0m 的密集队形下，验证间距不跌破安全距离、间距违规时必处于避碰模式、模式切换次数有界、加速度不超限。

## 三、大偏差渐进恢复

跟随者因绕障/故障偏离期望位置超过 `RecoverEnter`(2.0m) 时进入恢复模式。**不使用比例纠偏**（大误差下比例项会产生瞬时速度突变），而是：

```
v_corr  = clamp(KRec · e, RecoverSpeed)   // 纠偏速度限幅 1.0 m/s
v_target = clamp(v_des + v_corr, VMax)     // 目标速度再限幅
a       = KRecV · (v_target − v)           // 跟踪目标速度，最终 |a| ≤ AMax
```

误差收敛到 `RecoverExit`(0.5m，滞回) 以下才退出恢复模式回到正常队形控制。全程加速度、速度连续有界，无突变。测试 `TestRecoveryBoundedAcceleration` 验证 8.5m 偏差下恢复全程 `|a| ≤ AMax`、`|v| ≤ VMax` 且最终收敛。

## 参数表（`DefaultParams`）

| 参数 | 值 | 含义 |
|---|---|---|
| AMax / VMax | 2.0 / 2.5 | 加速度/速度硬限幅 |
| KP / KV | 2.0 / 2.5 | 队形 PD 增益 |
| DSafe | 1.0 m | 最小安全距离 |
| AvoidEnter / AvoidExit | 1.6 / 2.0 m | 避碰滞回阈值 |
| KAvoid / AvoidFormWeight | 6.0 / 0.25 | 避碰增益 / 避碰时队形权重 |
| RecoverEnter / RecoverExit | 2.0 / 0.5 m | 恢复滞回阈值 |
| RecoverSpeed | 1.0 m/s | 恢复纠偏速度上限 |
| ErrLimit | 1.2 m | 队形误差超限报警阈值 |
