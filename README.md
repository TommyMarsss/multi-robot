# 多机器人编队保持：领航-跟随控制

纯 Go 标准库实现的领航-跟随编队控制器，包含：路径坐标系队形定义、
转弯几何形变修正、跟随者间避碰仲裁、大偏差渐进恢复，以及单文件
HTML 轨迹回放报告。前端为原生 HTML/CSS/JavaScript，无任何第三方依赖。

## 运行

```bash
go run ./cmd/sim     # 仿真并在当前目录生成 report.html
go test ./...        # 自动化测试
open report.html     # 浏览器中逐帧回放
```

## 一、队形坐标定义与转弯几何形变

跟随者的期望偏移**不**使用世界系固定笛卡尔偏移，而是定义在随领航者
航向旋转的**路径坐标系**（Frenet 系）中（`formation/formation.go`）：

- `Along`：沿领航者航向的切向偏移（前为正）
- `Across`：垂直于航向的法向偏移（左为正）

设领航者状态为位置 `p_L`、航向 `θ`、转弯率 `ω`，偏移 `d=(Along,Across)`，
则期望位置与期望速度（前馈）为：

```
p_des = p_L + R(θ)·d
v_des = v_L + ω·R(θ)·J·d        J(a,b) = (-b, a) 为 90° 旋转算子
```

`v_des` 中的 `ω·R(θ)·J·d` 即**转弯时的偏移修正项**：它让全队绕同一瞬时
转弯中心以相同角速度 `ω` 运动 —— 外侧跟随者期望线速度按半径比例放大，
内侧减小（半径 8m 的转弯中，法向 ±2m 的跟随者期望速度分别为 2.5 与
1.5 m/s）。若使用世界系固定偏移，转弯时内外侧速度被迫一致，队形会被
拉扯甚至导致跟随者相撞。

## 二、避碰与队形冲突的仲裁策略

控制器每步输出（`formation/controller.go`）：

```
a = (1-w)·aForm + w·aAvoid,   最后统一限幅 |a| ≤ Amax
```

- **编队项** `aForm`：带前馈的速度跟踪律 `a = Kd·(vDes + Kp·e − v)`。
- **避碰项** `aAvoid`：对进入 `DAvoid` 的每个邻居，沿两者连线施加斥力
  `KAvoid·wi`，并叠加接近速度阻尼 `KDamp·max(0, closing)`。
- **优先级仲裁**：权重 `w = clamp((DAvoid − d)/(DAvoid − DSafe), 0, 1)`
  是最近邻居距离的**连续函数** —— 距离 ≥ `DAvoid` 时纯编队，≤ `DSafe`
  时避碰完全接管，中间平滑过渡。因为 `w` 连续，指令不会在两个目标间
  跳变，从机制上避免震荡；避碰事件标志另加迟滞（进入 `DAvoid`、退出
  `DAvoid×1.15`），防止报告抖动。
- **可行性**：合成指令统一按 `Amax` 限幅、积分后速度按 `Vmax` 限幅，
  输出永不超出机器人动力学能力。

当队形过密（期望间距 < `DSafe`）时，仲裁结果是把跟随者稳定在
`[DSafe, DAvoid]` 之间的折中距离上（避碰优先于队形精度），而不是在
两个不可同时满足的目标间往复震荡。

## 三、丢失同步后的渐进恢复

比例纠偏 `Kp·e` 在误差 `e` 很大时会产生速度突变。恢复策略是对**纠偏
速度**限幅而非对误差限幅：

```
vCorr = clampMag(Kp·e, vCap)
vCap  = RecoverVel   当 |e| > RecoverDist（恢复模式）
        Vmax         否则
```

大偏差时跟随者以至多 `RecoverVel` 的相对速度平缓汇入队形，接近后
自动退出恢复模式。全程加速度仍受 `Amax` 约束，速度变化率有界
（`|Δv| ≤ Amax·dt`），不存在瞬时跳变。

## 四、HTML 回放报告

`go run ./cmd/sim` 生成的 `report.html` 是单一静态文件（轨迹数据以
JSON 内嵌，无服务、无外部依赖），浏览器打开后：

- 逐帧回放领航者（白色三角形，带航向）与全部跟随者轨迹；
- **红色圆环**高亮避碰触发帧，**橙色圆环**高亮队形偏差超限帧；
- 灰色小叉为各跟随者期望位置，深色圆为安全半径 `DSafe/2`；
- 侧栏实时显示各跟随者偏差/加速度/状态，事件列表可点击跳转帧；
- 支持播放/暂停、0.5×–4× 变速、进度条拖帧。

| `TestAvoidanceArbitration` | 过密队形下不违反安全距离、避碰触发、无抖动、加速度不超限、稳态收敛到折中距离 |
| `TestRecoveryBoundedAcceleration` | 20m 大偏差恢复：加速度 ≤ Amax、速度无跳变、纠偏速度限幅、最终收敛 |

```
  formation_test.go

```
